#[T-rex runner](https://fatemehsooki.github.io/Project-T-rex-Runner/)

A browser-based endless runner inspired by Google's iconic Chrome Dino game, built from scratch using HTML, CSS, JavaScript, and Tailwind CSS.

![Gameplay Screenshot]<img width="1920" height="1080" alt="image" src="img/T-rex screen" />


## 🎮 Overview

This project recreates the core mechanics of the Chrome T-Rex Runner while focusing on clean front-end architecture, DOM manipulation, collision detection, and game state management.

The game features dynamically generated obstacles, keyboard-controlled jumping mechanics, and real-time collision detection to create an engaging endless runner experience.

## ✨ Features

* Procedurally generated cactus obstacles
* Spacebar-controlled jump animation
* Real-time collision detection
* Endless runner gameplay
* Lightweight implementation with Vanilla JavaScript
* Responsive and clean user interface
* Tailwind CSS styling

## 🛠️ Tech Stack

* HTML5
* CSS3
* Tailwind CSS
* JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Press **Space** to jump
4. Avoid obstacles and survive as long as possible
